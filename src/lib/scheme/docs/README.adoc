== Ambito corrente

Motore in analisi:

- AST: costruzione nodi e visitor
- Lexer: tokenizzazione sorgente Scheme
- Parser: sorgente -> ProgrammaAST
- Stepper: riduzione small-step
- Formatter: rendering simbolico e timeline snapshot

== Convenzioni

- Ogni API pubblica deve avere JSDoc con precondizioni, postcondizioni, errori.
- Ogni esempio in docs deve essere eseguibile o verificabile via test.
- Ogni modifica semantica richiede aggiornamento della matrice di tracciabilita.

== Build documentazione

Da questa cartella:

[source,bash]
----
./build-docs.sh html
----

Output generato in `docs/dist/html`.

Per PDF:

[source,bash]
----
./build-docs.sh pdf
----

Per generare entrambi:

[source,bash]
----
./build-docs.sh all
----
