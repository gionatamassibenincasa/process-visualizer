Questa cartella contiene la documentazione tecnica del motore dell'interprete Scheme (`src/lib/scheme`) orientata a:

- comprensione umana (architettura, semantica operativa, integrazione web)
- consumo da LLM (contratti API espliciti, output deterministici, esempi canonici)
- integrazione API verso la web app (timeline di riduzione AST, streaming dei passi, istantanee degli ambienti)

== Ambito corrente

Modulo Scheme in `src/lib/scheme`:

- **AST** (`ast/`): costruzione nodi (`ProgrammaAST`, `AtomoAST`, `DefineAST`, `LambdaAST`, `IfAST`, `AndAST`, `OrAST`, `CondAST`, `ApplicazioneAST`, `CitazioneAST`) e pattern Visitor.
- **Lexer** (`lexer/`): tokenizzazione del sorgente Scheme (`analizzatoreLessicale`, `TipoDiParole`).
- **Parser** (`ast/parser.ts`): trasformazione token -> `ProgrammaAST` a discesa ricorsiva.
- **Runtime & Ambienti** (`runtime/`): gestione scope lessicale (`Ambiente`), profili registrati (`standard`, `minimo-numeri-naturali`, `nat-add-sot-min`), tipi di valore (`ValoreScheme`, `Chiusura`, `FunzionePrimitiva`).
- **Stepper** (`runtime/stepper.ts`): motore di riduzione small-step (`StepperScheme`), supporto sia per l'intera timeline che per lo streaming via generatori (`passiStream`).
- **Formatter** (`ast/formatter.ts`): rendering simbolico canonico e produzione di istantanee timeline per la UI.
- **CLI** (`cli/stepper-cli.ts`): interfaccia a riga di comando per l'ispezione delle riduzioni con flag `--json`, `--max-passi`, `--ambiente`.

== Convenzioni

- Ogni file sorgente `.ts` in `src/lib/scheme` comincia con il commento del percorso di file (es. `// file: src/lib/scheme/...`).
- Ogni simbolo esportato dispone di documentazione JSDoc estesa con precondizioni, postcondizioni, eccezioni lanciate ed esempi d'uso.
- Ogni esempio o contratto definito nei documenti è verificato da test automatizzati (`bun test`).

== Build documentazione

[source,bash]

./build-docs.sh html
----

Output generato in `docs/dist/html`.

[source,bash]

----

Per generare entrambi:

[source,bash]

./build-docs.sh all
