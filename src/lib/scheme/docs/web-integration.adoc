== Obiettivo

Fornire indicazioni e specifiche per integrare la libreria Scheme (`src/lib/scheme`) in una Web Application Svelte/Vite per la visualizzazione interattiva dell'esecuzione e della riduzione dell'AST passo-passo.

== Flusso di Esecuzione Consigliato

1. L'utente inserisce o seleziona il codice sorgente Scheme nel componente editor (es. CodeMirror).
2. La Web App rileva l'ambiente dichiarato via direttiva `; ambiente: <id>` oppure usa il profilo scelto dall'utente.
3. Il worker o la funzione della UI invoca `StepperScheme.daSorgente(sorgente)` ottenendo l'istanza dello stepper.
4. Per visualizzazione sequenziale completa: invoca `stepper.passiDaSorgente(sorgente, maxPassi)` e formatta con `FormatterScheme.formattaTimelineStepping(passi)`.
5. Per elaborazioni incrementalmente reattive (es. animazione passo-passo o grandi programmi): usa il generatore `stepper.passiStream(sorgente, maxPassi)`.
6. La UI renderizza in parallelo:
   - Il sorgente Scheme formattato nel passo corrente.
   - La regola di riscrittura applicata (`regolaApplicata`).
   - L'albero di scope dell'ambiente corrente (`SnapshotAmbiente`).
   - I controlli di navigazione (Prima, Precedente, Play/Pause, Successivo, Ultima).

== CLI di Tracing per Debugging

Per generare la traccia di riduzione direttamente da terminale:

[source,bash]
----
./src/lib/scheme/scripts/stepper-trace.sh ./src/lib/scheme/cli/01_atomi.scm --max-passi 200
----

Per output JSON strutturato (equivalente a quanto ricevuto dal frontend):

[source,bash]
----
./src/lib/scheme/scripts/stepper-trace.sh ./src/lib/scheme/cli/01_atomi.scm --max-passi 200 --json
----

== Struttura di Stato Consigliata nel Componente Web

[source,typescript]
----
import type { SnapshotPassoStepping } from '$lib/scheme/ast/formatter';
import type { CodiceErroreScheme } from '$lib/scheme/docs/error-model';

export interface StatoVisualizzatoreScheme {
  sorgente: string;
  idAmbienteSelezionato: string;
  passi: SnapshotPassoStepping[];
  indicePassoCorrente: number;
  inEsecuzione: boolean;
  errore: null | {
    codice: CodiceErroreScheme;
    messaggio: string;
  };
}
----

== Payload JSON DTO di Esempio (`SnapshotPassoStepping`)

[source,json]
----
{
  "indice": 0,
  "regola": "Programma: forma 1/2 -> Definizione variabile: 'x' = 10",
  "precedente": "(define x 10)\n(+ x 5)",
  "successivo": "10\n(+ x 5)",
  "terminato": false,
  "haRidotto": true,
  "focusProgramma": {
    "indiceForma": 1,
    "totaleForme": 2
  },
  "ambiente": {
    "scope": [
      {
        "binding": {
          "x": "10",
          "+": "#<primitiva>"
        }
      }
    ]
  }
}
----

== Requisiti UX Consigliati

- **Pannello Editor Sorgente:** Con evidenziazione della sintassi Scheme.
- **Pannello Riduzione AST:** Visualizzazione del codice Scheme corrispondente all mezza riduzione corrente.
- **Pannello Spiegazione Regola:** Banner evidenziato contenente `regola`.
- **Pannello Ispezione Ambienti:** Visualizzazione ad albero degli scope (`SnapshotAmbiente`) con i relativi legami `simbolo -> valore`.
- **Timeline Interattiva:** Barra di avanzamento o elenco dei passi selezionabili direttamente.
- **Gestione Errori:** Componente dedicato per segnalare syntax error o runtime error con indicazione del passo.
